# 🎯 AI Object Detection using TensorFlow.js

An AI-powered Object Detection web application built using HTML, CSS, JavaScript, TensorFlow.js and COCO-SSD model.

This application allows users to upload images and automatically detect objects with confidence scores using real AI.

## ✨ Features

- 📷 Upload image functionality
- 🤖 Real AI object detection
- 🎯 Detect multiple objects
- 📊 Confidence score prediction
- 🎨 Modern responsive UI
- ⚡ Fast browser-based detection

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- COCO SSD Model
